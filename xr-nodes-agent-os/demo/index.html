System Architecture

The internal flow of an AI-Native Operating Layer.

1. User Request

"Atomize research on transformer architectures"

2. Intent Detection

Antigravity orchestrator analyzes request and classifies intention.

3. Task Planning

Decomposes request into a 4-step execution pipeline.

4. Agent Execution & Tools

Specialized agents (Researcher, Atomizer, Linker) execute tools sequentially.

5. Vault Mutator

Applies structured Markdown edits to the Obsidian vault.

6. Verification & Telemetry

Checks constraints, logs telemetry, and returns final summary to User.
