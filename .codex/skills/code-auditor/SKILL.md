# Code Auditor Skill

## 🎯 Goal
Invoke the `code-auditor` subagent to conduct static code analysis, security vulnerability audits, and quality reviews on codebase files.

## 📋 Execution Steps
1. Perform static analysis on target code files.
2. Flag potential injection vulnerabilities, unvalidated inputs, or hardcoded credentials.
3. Assess memory safety, performance bottlenecks, and anti-patterns.
4. Provide structured audit report with actionable remediation steps.
