# Planner Agent Skill

## 🎯 Goal
Invoke the `planner-agent` subagent to formulate project plans, sequence execution tasks, route work to specialized subagents, and enforce authority rules.

## 📋 Execution Steps
1. Analyze user prompt and vault requirements.
2. Formulate step-by-step project plan with clear milestones.
3. Identify required subagents and automations.
4. Verify execution safety against core governance rules.
5. Present structured project plan to user.
