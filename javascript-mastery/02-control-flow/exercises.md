# Exercises: Control Flow

## Conditional Problems (15)

### 🟢 Beginner
1. **Voting Age:** Write a script that checks if a user is 18 or older and prints "Can vote" or "Cannot vote".
2. **Grade Checker:** Given a score (0-100), print 'Pass' if score is >= 50, else 'Fail'.
3. **Traffic Light:** Given a color ('red', 'yellow', 'green'), print the action ('stop', 'slow down', 'go').
4. **Even or Odd:** Check if a number is even or odd.
5. **Positive/Negative:** Check if a number is positive, negative, or zero.

### 🟡 Intermediate
6. **BMI Calculator:** Calculate BMI from weight and height, then classify as 'Underweight', 'Normal', 'Overweight', or 'Obese'.
7. **Tax Bracket:** Given an income, apply different tax rates based on standard tax brackets.
8. **Login Validator:** Check if a `username` is 'admin' and `password` is 'secret123'.
9. **Discount System:** Apply a 10% discount if cart total > 100, and 20% if total > 200.
10. **Leap Year:** Determine if a given year is a leap year.

### 🔴 Advanced
11. **Multi-Condition Validator:** Validate a password: length > 8, contains a number, contains an uppercase letter.
12. **Scoring System:** Letter grade (A, B, C, D, F) based on a 0-100 score.
13. **Time of Day:** Given a 24-hour time string "14:30", print "Morning", "Afternoon", or "Evening".

### 🔥 Challenge
14. **Credit Card Fraud Rule:** Given a transaction (amount, country, time), flag it as fraudulent based on specific complex rules.
15. **Game State Engine:** Given health, stamina, and enemy proximity, decide the best action: 'run', 'attack', or 'heal'.

## Loop Problems (15)

### 🟢 Beginner
16. **Counting:** Print numbers from 1 to 10.
17. **Summing:** Sum the numbers from 1 to 100.
18. **Blast Off:** Print numbers from 10 down to 1, then "Blast off!".
19. **Evens Only:** Print all even numbers up to 20.
20. **String Printer:** Print each character of a string on a new line.

### 🟡 Intermediate
21. **Multiplication Table:** Print the 7x multiplication table up to 10.
22. **Array Search:** Given an array, find the index of a specific value.
23. **Accumulation:** Multiply all elements in a numeric array together.
24. **Reverse Array:** Reverse an array using a loop (no built-in `.reverse()`).
25. **Vowel Counter:** Count vowels in a given string.

### 🔴 Advanced
26. **Nested Patterns:** Print a 5x5 grid of '*'.
27. **Right Triangle:** Print a right triangle of '*' of height `N`.
28. **Matrix Flatten:** Convert a 2D array into a 1D array using nested loops.

### 🔥 Challenge
29. **Matrix Transpose:** Transpose a 2D matrix.
30. **Inventory Processor:** Iterate through an array of product objects and calculate the total value of all items in stock.

## Mixed Logic Problems (10)
31. **FizzBuzz:** Numbers 1 to 100. Divisible by 3: "Fizz", by 5: "Buzz", by 3 & 5: "FizzBuzz".
32. **Number Analyzer:** Print if a number is prime or not for numbers 1 to 50.
33. **Simple Menu:** Using a `while` loop and `switch`, simulate a simple ATM menu.
34. **Grade Distribution:** Given an array of scores, count how many A's, B's, etc.
35. **Largest Element:** Find the largest number in an array.
36. **Longest Word:** Find the longest word in a sentence.
37. **Palindrome Checker:** Check if a string is a palindrome.
38. **Duplicate Remover:** Remove duplicates from an array using loops.
39. **Fibonacci:** Generate the first `N` numbers of the Fibonacci sequence.
40. **Cart Totalizer:** Given an array of cart items, calculate total with specific tax rules per item type.
