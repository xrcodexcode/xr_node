# Level 18 Exercises

## 🟢 Beginner
1. Implement a counter function using closures.
2. Create a function that caches the result of a calculation (basic memoization).
3. Use a `Set` to remove duplicates from an array.
4. Write a generator function that yields powers of 2.
5. Implement a basic `pipe` function that takes two functions and combines them.

## 🟡 Intermediate
6. Write a debounce function from scratch.
7. Write a throttle function from scratch.
8. Create a custom iterable object that iterates over keys of an object.
9. Use a `Map` to count the frequency of characters in a string.
10. Implement a manual curried version of a function that takes 3 arguments.

## 🔴 Advanced
11. Create a `Proxy` that validates an object so that its 'age' property can only be set to a number between 0 and 120.
12. Implement a `WeakMap` to store private data for a class.
13. Write a generalized `compose` function that takes any number of functions.
14. Implement an Event Emitter class from scratch using `Map`.
15. Write a function that automatically curries another function based on its `.length`.

## 🔥 Challenge
16. Build a mini reactive state library using Proxies. When a state property is changed, any subscribed listener functions should be called automatically with the new value.
