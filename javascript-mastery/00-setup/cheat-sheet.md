# Level 0: Setup Cheat Sheet

## Node Version Management
Always use a version manager to easily switch Node.js versions.
- **Mac/Linux:** `nvm` (Node Version Manager)
- **Windows:** `nvm-windows`

### NVM Commands 🟢
| Command | Action |
|---|---|
| `nvm install 18` | Install Node v18 |
| `nvm use 18` | Switch to Node v18 |
| `nvm ls` | List installed versions |
| `node -v` | Check active Node version |

## VS Code Essentials 🟡
Must-have extensions for JS Developers:
- **ESLint:** Lints code for errors and style issues.
- **Prettier - Code formatter:** Auto-formats code on save.
- **Live Server:** Runs a local development server for static files.
- **JavaScript (ES6) code snippets:** Shortcuts for writing code faster.

### VS Code Shortcuts 🟢
| Action | Windows/Linux | Mac |
|---|---|---|
| Command Palette | `Ctrl + Shift + P` | `Cmd + Shift + P` |
| Format Document | `Shift + Alt + F` | `Shift + Option + F` |
| Toggle Terminal | `Ctrl + ~` | `Cmd + ~` |

## Chrome DevTools 🔴
- **Console:** Run JS snippets and view logs.
- **Elements:** Inspect and modify the DOM / CSS.
- **Sources:** Set breakpoints and step through JavaScript execution.
- **Network:** Monitor API requests and load times.
