# Level 5 — Arrays Cheat Sheet

| Method | Mutates? | Return Value | Purpose |
|---|---|---|---|
| `push()` | Yes | New length | Add to end |
| `pop()` | Yes | Removed item | Remove from end |
| `unshift()` | Yes | New length | Add to start |
| `shift()` | Yes | Removed item | Remove from start |
| `splice()` | Yes | Removed items array | Add/Remove anywhere |
| `slice()` | No | New array | Extract portion |
| `concat()` | No | New array | Merge arrays |
| `map()` | No | New array | Transform elements |
| `filter()` | No | New array | Filter elements |
| `reduce()` | No | Accumulated value | Accumulate values |
| `forEach()` | No | `undefined` | Iterate |
| `sort()` | Yes | Sorted array (same ref) | Sort |
| `reverse()`| Yes | Reversed array (same ref)| Reverse |
