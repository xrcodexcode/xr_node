# String Exercises

## 🟢 Beginner (10 Exercises)
1. **Reverse String:** Write a function that takes a string and returns it reversed.
2. **Count Vowels:** Count the number of vowels (a, e, i, o, u) in a string.
3. **Capitalize First Letter:** Capitalize the first letter of a given string.
4. **Truncate String:** Truncate a string to a certain number of characters and add '...'.
5. **Check Empty:** Check if a string is empty or contains only whitespace.
6. **Initials:** Given a full name (e.g., 'John Doe'), return the initials ('J.D.').
7. **Repeat String:** Repeat a given string `n` times without using `.repeat()`.
8. **String to Array:** Convert a comma-separated string into an array of words.
9. **Count Words:** Return the number of words in a string.
10. **Find Character:** Return the first index of a specific character in a string.

## 🟡 Intermediate (10 Exercises)
11. **Palindrome Check:** Check if a string is a palindrome (reads same forwards and backwards).
12. **Word Counter (Object):** Return an object containing the frequency of each word in a string.
13. **Slug Generator:** Convert a string into a URL-friendly slug (e.g., "Hello World" -> "hello-world").
14. **Censoring Words:** Given a string and an array of banned words, replace banned words with '*'.
15. **Camel Case:** Convert a hyphenated or snake_case string to camelCase.
16. **Snake Case:** Convert a camelCase string to snake_case.
17. **Title Case:** Capitalize the first letter of every word in a sentence.
18. **Mask Credit Card:** Mask all but the last 4 digits of a credit card number with '#'.
19. **Extract Domain:** Extract the domain name from a URL (e.g., 'https://www.github.com' -> 'github.com').
20. **Anagram Check:** Check if two strings are anagrams of each other.

## 🔴 Advanced (5 Exercises)
21. **Template Engine:** Write a function `render(template, data)` that replaces `{{key}}` in template with `data[key]`.
22. **String Compression:** Compress strings like 'aabcccccaaa' into 'a2b1c5a3'.
23. **URL Parser:** Parse a URL string into an object containing protocol, host, path, and query params.
24. **Longest Substring:** Find the length of the longest substring without repeating characters.
25. **Isomorphic Strings:** Check if two strings are isomorphic (characters can be mapped 1-to-1).

## 🔥 Challenge (5 Exercises)
26. **Mini Markdown Parser:** Convert basic markdown (`**bold**`, `*italic*`) to HTML tags.
27. **Search Highlight:** Given a string and a search term, wrap the search term in `<mark>` tags (case-insensitive).
28. **Regex Email Validator:** Write a comprehensive function to validate an email using Regex.
29. **Roman Numeral Converter:** Convert a Roman numeral string to an integer.
30. **Text Justification:** Format an array of words into a string array where each line has exactly `k` characters (left and right justified).
