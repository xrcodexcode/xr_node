# JavaScript Mastery - Revision System

Welcome to the Revision system of the JavaScript Mastery curriculum. This system is designed to ensure long-term retention of JavaScript concepts through a structured, multi-tiered revision strategy.

## The Three Pillars of Revision

### 1. [Quick Revision](./quick-revision.md)
5-minute review sheets for each level. Use these to quickly refresh your memory on key concepts, critical code patterns, and common gotchas. Best used a day or two after learning a new topic.

### 2. [Practice Revision](./practice-revision.md)
10-15 minute coding tasks that revisit core concepts from each level. These are mini practice sessions designed to reinforce muscle memory and practical application without requiring a significant time investment.

### 3. [Delayed Revision](./delayed-revision.md)
Cumulative revision problems that combine concepts from multiple levels. These are designed to be tackled periodically (e.g., after completing Level 3, Level 6, etc.) to ensure older concepts integrate smoothly with newer ones.

## Getting Started

To get the most out of this system, follow the [Spaced Repetition Schedule](./spaced-repetition-schedule.md). This schedule outlines exactly when to use each type of revision material for optimal learning and retention.
