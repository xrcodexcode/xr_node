# Spaced Repetition Schedule

To maximize retention and minimize forgetting, follow this schedule for every new concept or level you learn.

## The Strategy

Spaced repetition relies on reviewing information at gradually increasing intervals. When you first learn something, you forget it quickly. Each time you review it, the memory trace strengthens, and the forgetting curve flattens.

## The Schedule

### Day 1: Learn & Code
- **Action:** Read the lesson, type out all the examples, complete the Worksheet.
- **Focus:** Understanding the *Why* and the *How*.

### Day 2: Quick Review
- **Action:** Read the [Quick Revision](./quick-revision.md) sheet for that level.
- **Time:** 5 minutes.
- **Focus:** Refreshing syntax and key concepts.

### Day 4: Practice Revision
- **Action:** Complete the [Practice Revision](./practice-revision.md) task for that level. Write the code from scratch.
- **Time:** 10-15 minutes.
- **Focus:** Building muscle memory and identifying weak spots.

### Day 7: Delayed Revision (Cumulative)
- **Action:** If you've reached a checkpoint (e.g., Level 3, 7, 13, 18), do the [Delayed Revision](./delayed-revision.md) problems.
- **Time:** 30-60 minutes.
- **Focus:** Integrating new concepts with old ones. Context switching.

### Day 14: Second Practice
- **Action:** Redo the Practice Revision task, but try to do it faster or in a different way (e.g., use an arrow function instead of a regular function).
- **Time:** 10 minutes.

### Day 30: Final Review & Project Integration
- **Action:** Ensure the concept is being used in a larger Mini Project. If not, quickly review the Quick Revision sheet.
