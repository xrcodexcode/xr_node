# Writing Agent Skill

## 🎯 Goal
Invoke the `writing-agent` subagent to generate comprehensive synthesis notes, wiki pages, articles, and summaries from vault atomic nodes.

## 📋 Execution Steps
1. Gather related atomic nodes and source references.
2. Structure narrative layout with clear headings and logical progression.
3. Write clean, rep-free, objective prose following vault writing standards.
4. Insert Obsidian wikilinks and preserve citation traceability.
5. Save draft for user review.
